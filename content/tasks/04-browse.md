Every paper Magic set, newest first.

## The sets list {#sets-list} [screen]
Where: the `Browse` tab — the first tab, where the app opens
- Title `Browse` at the top
- Sets grouped by the day they came out → {#sets-dates}
- Each set on a row → {#set-row}
- Pull the list down — check for new sets
- Tap a set — its cards → {#set-page}

## Release dates {#sets-dates}
- Each group of sets sits under the day it came out, newest at the top
- The date stays pinned at the top while you scroll through its sets
- Within a day, the biggest set comes first
- Online-only sets and empty sets aren't listed

## Upcoming sets {#upcoming-sets}
Where: Browse; Explore → Upcoming sets
- An hourglass before the date — the set isn't out yet
- Upcoming sets sit above every released set
- Open one — the cards revealed so far → {#set-page}
- No packs to open until the set is out → {#set-info}

## A set's row {#set-row}
Where: Browse; Search's results; Explore → Released sets
- Symbol — the set's mark, as printed on its cards
- Name — e.g. Tarkir: Dragonstorm
- Code — the set's three or four letters in a grey pill, e.g. `TDM`
- Number of cards — e.g. `286 Cards`
- Chevron › — tap the row to open the set

## Sets that belong together {#set-families}
- A main set and its extras share one box: its Commander decks, tokens, promos
- The main set is first, its extras under it
- The extras sit under the main set's date, even if they came out another day

## If the list won't load {#sets-failed}
- A spinner — still loading
- `Failed to load` — tap `Retry`
- Without a connection, the sets you've loaded before still show
