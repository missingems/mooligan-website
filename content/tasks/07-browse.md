Where: the `Browse` tab, the first at launch → {#tab-bar}

## Sets list {#sets-list}
Where: Browse on iPhone; its left column on iPad → {#browse-columns}
- Title `Browse`
- Pull down to refresh
- Tap a set → {#set-page}

### Date sections {#sets-date-section}
- The release date heads each section, newest first
- On iPhone the date stays at the top as you scroll its sets
- Digital-only sets and empty sets are left out

### Upcoming sets {#upcoming-sets}
Where: Browse; Explore → upcoming sets
- An hourglass before the date — the set is still to come
- Upcoming sets sit above every released one
- Never opened by themselves on iPad
- No `Open … Booster` in their details → {#set-info}

### Set row {#set-row}
Where: Browse; Explore → released sets; Search → sets
- Set symbol
- Set name
- Set code — in a pill, e.g. `TDM`
- Number of cards — e.g. `286 Cards`
- Chevron
- A set and its extras share one box — Commander decks, tokens, promos
- The open set has a soft plate behind it, iPad
- Tap it → {#set-page}

### Loading and offline {#sets-states}
- A large spinner while the sets load
- `Failed to load` with `Retry` — only when nothing was saved
- Offline, the saved list shows

### Keyboard {#sets-keyboard}
- ↑ ↓ — move through the sets; on iPad the set opens as the key is let go
- Return or Space — open the set, iPhone
- Escape — let go of the highlight, iPhone
- → — into the grid, iPad → {#set-grid-keyboard}

## Columns {#browse-columns}
Where: iPad, any orientation; an open iPhone Duo
- The sets, 320 pt wide, beside the open set → {#set-page}
- The newest released set opens by itself
- `No Set Open` — `Choose a set to see its cards.`
- `Hide Sets` / `Show Sets` — the grid takes the whole width, ⌃⌘S
- Half-open Duo: the sets grow to the fold
